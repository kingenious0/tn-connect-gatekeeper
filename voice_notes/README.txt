Place audio files (.mp3, .ogg, .opus, .m4a, or .wav) in this directory.
To send a voice note on command in a group or DM, use:
  vn [filename_without_extension]
Example: if you place a file named "hello.mp3" here, typing "vn hello" will cause the bot to send it as a WhatsApp voice note.
To see the list of available voice notes, type:
  vn list
